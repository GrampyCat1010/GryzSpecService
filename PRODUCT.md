# ГРУЗСПЕЦСЕРВИС
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
HTML5, CSS3, JavaScript modules, Python, FastAPI. Supabase PostgreSQL in production; SQLite for local development. Render Free deployment.

## Users
Водители грузового транспорта, частные владельцы и представители автопарков. Нужно быстро записаться на СТО, вызвать помощь или обратиться по корпоративному обслуживанию.

## Capabilities and Constraints
MasterPromt.txt — основной источник. Доп информация.txt — вспомогательная старая идея. Пять пунктов навигации; верхняя панель на компьютере, нижняя на телефоне. Чат открывается поверх текущего раздела. Работа 24/7, без искусственного ограничения территории. Корпоративная стоимость определяется менеджером. Фото работ не нужны. Личные заявки включают выбор ремонта, электрики, помощи, эвакуации и запчастей.

Заявка сначала сохраняется в БД, затем отправляется в Telegram и на почту. Фото удаляются после доставки. Секреты и данные организации пользователь добавляет в .env. SQL для Supabase предоставляется отдельно. Реальные отзывы отображаются официальным виджетом Яндекса.

## Brand Commitments
Красный, белый, графитовый, серый из ImagesForCoding. Массивные заголовки и красная плашка названия. Кот из cat.png — только консультант. four.jpg — принцип нижней панели, five.jpg — крупная выдвижная панель чата.
